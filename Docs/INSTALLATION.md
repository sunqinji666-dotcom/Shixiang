# 拾响 1.0 安装说明

版本：1.0.0 · Build 111

官网：https://shixiang.jack-sun.com

## 系统要求

- Apple Silicon Mac（M 系列芯片）
- macOS 14.0 或更高版本
- 建议预留至少 4 GB 可用空间用于安装与本地索引

## 一步安装

1. 双击 `拾响-1.0.0-Build111.dmg`。
2. 将左侧的 `拾响.app` 拖到右侧的 `Applications` 文件夹。
3. 拖拽完成后，从“应用程序”文件夹打开拾响。

拾响已经内置本地 AI 搜索运行时与模型，不需要安装 Python、Homebrew、Xcode 或额外 AI 环境。macOS 14.0–26.1 可使用全部非 AI 功能；本地 AI 自然语言搜索需要 macOS 26.2 或更高版本。App 安装包本身保持轻量；同一百度网盘分享中另行赠送作者多年积累、筛选和整理的 5 万+ 附加音效库，来源包括公开互联网资源与作者自行购买的专业素材。用户也可以完全不下载赠送库，直接导入自己的音效文件夹。

赠送音效素材的版权归原作者或发行方，不同内容的使用范围可能不同，具体授权以附加包内的来源与授权说明为准。正式对外分享前，应只保留已经确认允许再分发的内容。

## 第一次打开被 macOS 拦截

本交付包使用本地稳定签名，但没有 Apple Developer ID 公证。若 macOS 第一次打开时提示无法验证开发者：

1. 按住 Control 点击“拾响.app”，选择“打开”。
2. 如果仍被拦截，前往“系统设置 → 隐私与安全性”，点击“仍要打开”。
3. 交付文件夹附带的 `macOS Assistant.app` 也可作为辅助工具；它不是拾响的运行依赖。

不要关闭系统安全功能，也不要安装来源不明的脚本。
