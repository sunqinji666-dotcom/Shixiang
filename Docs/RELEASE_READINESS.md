# 拾响 · 独立售卖发布准备

这份清单把“本地可用版本”和“可直接售卖/上架版本”分开，避免把临时签名误当成正式发布。

- BPM、近似响度、调性识别、变调试听与 24-bit WAV 导出。

## 仍需外部发布条件

- **Developer ID Application**：需要在本机钥匙串安装 Apple Developer ID 证书，并设置 `SHIXIANG_CODESIGN_IDENTITY`。
- **Apple 公证**：需要用 `xcrun notarytool store-credentials` 保存 Profile，并设置 `SHIXIANG_NOTARY_PROFILE`。
- **销售层（当前明确排除）**：许可/激活服务、隐私政策网站、支持邮箱、支付和在线更新在正式售卖阶段另行接入；本地版当前不联网、不上传音频或索引。

## 一键前置检查

```bash
cd /path/to/Shixiang
./scripts/release-preflight.sh
```

脚本不会读取或打印证书私钥、Profile 内容或任何用户音效，只检查证书类型和 Profile 是否已配置。
