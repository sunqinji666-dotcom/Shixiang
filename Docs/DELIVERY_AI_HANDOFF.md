# 拾响 1.0.0 · Build 111 交付与 AI 启动说明

官网：https://shixiang.jack-sun.com

## 交付内容

本文件夹对应拾响 1.0.0 正式版 Build 111。目标设备必须是 Apple Silicon Mac，并运行 macOS 14.0 或更高版本。macOS 14.0–26.1 可使用资料库、普通搜索、试听、整理、声音工作台和拖入剪辑软件；本地 AI 自然语言搜索需要 macOS 26.2 或更高版本。App 本身不内置音效库；空音效库时可从软件内前往拾响官网领取作者多年积累、筛选和整理的 5 万+ 附加音效库，来源包括公开互联网资源与作者自行购买素材，具体使用授权以附加包内说明为准。用户也可以完全不下载赠送库，直接导入自己的音效文件夹。

App 已将本地 AI 搜索运行时、Python 标准库与 Qwen 搜索模型放入应用资源。目标电脑不需要另装 Python、Homebrew、Swift、Xcode，也不需要联网下载模型。

## 用户安装

1. 双击 `拾响-1.0.0-Build111.dmg`。
2. 将左侧 `拾响.app` 拖入右侧 `Applications` 文件夹。
3. 拖拽完成后，从“应用程序”打开拾响。
4. 首次打开若被 macOS 拦截，按住 Control 点击 App 并选择“打开”；仍有提示时，前往“系统设置 → 隐私与安全性 → 仍要打开”。
5. 在拾响内导入自己的音效文件夹，等待本地索引完成。

发布文件夹附带 `macOS Assistant.app`，只用于辅助处理首次安全提示，不是拾响的运行依赖。

## 已知边界

- 当前 App 使用本机稳定签名身份完成签名，但未使用 Apple Developer ID 公证；另一台 Mac 首次打开时可能需要一次系统安全确认。
- App 只在本机建立音效索引和运行 AI 搜索，不上传音频或索引，不移动、改名或改写原始音频。
- 不支持 Intel Mac，不支持低于 macOS 14.0 的系统；macOS 14.0–26.1 不启用本地 AI 搜索。
