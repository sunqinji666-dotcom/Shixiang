## 系统与依赖

- Apple Silicon Mac（M 系列芯片）
- macOS 14.0 或更高版本；本地 AI 自然语言搜索需要 macOS 26.2 或更高版本
- 本地 AI 搜索运行时、Python 标准库与 Qwen 模型已内置
- 不需要 Python、Homebrew、Swift、Xcode 或额外模型
- App 本身不内置音效库；同一网盘另行赠送作者多年积累、筛选和整理的 5 万+ 附加音效库，用户也可以直接导入自己的音效文件夹
- 附加音效素材来源包括公开互联网资源与作者自行购买内容；对外发布版本必须附带来源与授权说明，并只保留已确认允许再次分发的素材
