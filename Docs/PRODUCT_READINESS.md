## 当前发布边界

Build 89 已具备本机长期使用与本地分享所需的核心能力、真实大库零读取/无持久化短路/共享索引快照/按需指纹刷新证据、有界预热内存、扫描前后安静的悬停门控、逐层惰性的超大侧栏、后台可取消且任务隔离的资料库体检、低成本覆盖计数的声音理解中心、收藏及元数据低延迟局部编辑、完整创作现场恢复、经过侧栏和体检结果页成品对照的中文无障碍语义、Final Cut Pro 实拖证据、播放器/工作台按声音隔离状态、旧语义任务失效和后台备份传输。全复用扫描临时峰值约 259 MB；超大侧栏首层展开内存增量已从约 31 MB 降到约 20 MB，但完整无障碍读取延迟仍有波动，后续继续审计。当前本地终极版之外仍有两类外部事项：

1. 若要公开分发，需要配置 Developer ID Application 证书和 `SHIXIANG_NOTARY_PROFILE`，通过 `release-preflight.sh` 与 Apple 公证脚本。
2. 许可、在线更新、支持邮箱、支付和联网音效服务属于孙哥明确排除的正式销售体系，本轮不接入。

因此当前包可以作为已验证的本地创作者版本使用，但在 Developer ID 与公证完成前不宣传为已公证的公开上架版本。
