# 拾响 · Final Cut Pro 手工烟测清单

这份清单用于真实 macOS 桌面环境。它不能由单元测试替代，完成后把结果和系统版本一起记录在本批发布记录中。

## 前置

- macOS 14 或更高版本
- Final Cut Pro 已安装并能新建一个空白资料库/项目
- 准备一个不含客户隐私的短 WAV 或 AIFF 测试音频
- 打开当前版本拾响，选择“本地音效库”

## 测试步骤

1. 在拾响导入测试音效文件夹，确认原目录和文件名显示正确。
2. 从音效列表行的拖拽区域按住，拖到 Final Cut Pro 时间线。
3. 确认时间线出现音频片段，片段文件名/时长与源文件一致。
4. 播放拾响中的另一段声音，再从底部播放器左侧声音图标拖入 Final Cut Pro。
5. 在播放器设置 A、B 区间，再拖出一次；确认时间线只出现 A/B 范围的临时 `.m4a` 片段。
6. 快速连续点击三段不同声音，确认上一段立即停止、下一段立即起播，缩略图回到未播放状态。
7. 在拾响中滚动到大目录，确认滚动、波形进度和音量拖动没有明显卡顿。
8. 回到 Finder 检查源文件：路径、文件名、修改时间和文件内容均未改变。
